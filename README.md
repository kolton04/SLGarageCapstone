# Full Stack S&L Garage Door Capstone

<img width="1266" height="1111" alt="Website Homepage" src="https://github.com/user-attachments/assets/b9846bc1-c505-4e7e-a7d2-609abcac7d6e" />


This repository contains the full-stack version of the S&L Garage Door website, originally developed to meet client's
requirements and my capstone project requirements.

The website includes a contact form, a MongoDB for storing customer messages, and an admin interface for 
managing submitted messages.

The live static version: [View the static repository](https://github.com/kolton04/SLGarageCapstone/tree/main)
## Features
  -Responsive garage door business website
  -Contact form for customer messages
  -MongoDB integration for message persistence
  -Admin interface for viewing, editing, and deleting messages

## Built With

-Node.js/Express
-MongoDB/Mongoose
-Handlebars
-HTML, CSS, and JavaScript
-Bootstrap

   2. Open the admin interface
   3. View the submitted message
   4. Test the available message management operations

## Project Outcome

After reviewing this version of the website, the client decided that a simpler static website better suited their needs. 
Their priority was to provide visitors with business information and encourage phone inquiries without needing to 
manage and online message system.

I retained the full-stack implementations demonstrating my experience with backend development, database 
integration, and CRUD functionality, while the client facing website was simplified to meet his needs. [Visit the client site] (https://sandlgaragedoor.net/)
